# PawLocal NZ 🐾

An Auckland-first pet sitting marketplace prototype.

## Demo
Open `index.html` locally, or publish this repository using GitHub Pages.

### GitHub Pages setup
Open **Settings → Pages → Build and deployment** and select **Deploy from a branch**, then **main** and **/(root)**. Save.

Features: sitter discovery, suburbs and services filters, price limits and a demonstration booking form.

**Prototype only:** Profiles are fictional. No accounts, actual bookings, identity checks or payments are provided. Avoid entering real personal information in the sample form.
